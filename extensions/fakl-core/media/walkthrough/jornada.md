# Set up FaKL-Code

The setup journey brings everything together. Each step shows what is ready,
what is missing and the button that fixes it. None of them is required.

- **Essentials:** language, what you use in VS Code, the theme, the AI
  providers you have and agent permissions.
- **Integrations:** GitHub, agents and skills from your own sources, notes
  vault, SSH, Hostinger, Lovable, email, phone remote control, voice, settings
  sync and the `fakl` CLI.

With no AI provider at all, the IDE works as a full editor. Come back to any
step with the **FaKL: Set up** command.

# Configurar a FaKL-Code

A jornada de configuração reúne tudo num lugar só. Cada etapa mostra o que já
está pronto, o que falta e o botão que resolve. Nenhuma é obrigatória.

- **Essenciais:** o idioma, o que você usa no VS Code, o tema, os provedores
  de IA que você tem e as permissões dos agentes.
- **Integrações:** GitHub, agentes e skills de fontes suas, vault de notas,
  SSH, Hostinger, Lovable, email, controle pelo celular, voz, sync de
  configurações e a CLI `fakl`.

Sem nenhum provedor de IA, a IDE funciona como um editor completo. Dá para
voltar a qualquer etapa pelo comando **FaKL: Configurar**.
