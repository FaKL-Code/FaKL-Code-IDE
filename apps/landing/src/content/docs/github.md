Entre com **Entrar no GitHub**. A barra do GitHub mostra a sua conta inteira, não só o repositório aberto:

- **Conta:** usuário, organizações e repositórios, com busca;
- **Atribuídos a mim**, **Revisão pedida** e **Meus PRs**;
- **Issues** e **Actions** de todos os repositórios, com filtros;
- **Notificações** agrupadas por repositório.

## Tela cheia

**Abrir o GitHub em tela cheia** abre um painel dentro do editor com início, busca, repositórios, arquivos, PRs, issues e execuções, com o Markdown renderizado. O token nunca chega ao painel.

## Ações

Em um PR: revisar, comentar, ver o diff de cada arquivo, fazer checkout e fazer merge. Numa execução das Actions: rodar de novo e ver o log do job. Numa issue: **Mandar para agentes**, que cria uma tarefa com ela.

Se uma organização usa SSO, **Diagnosticar acesso ao GitHub** mostra o que falta autorizar.
