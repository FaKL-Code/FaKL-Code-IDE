## Lovable

**Link repository to a Lovable project** associates the open repository with a project. Afterward, **Open in Lovable** takes you straight to it.

## Email

**Connect an email inbox** connects a mailbox over IMAP with TLS and an app password. The inbox appears in its own sidebar and each message opens as a document. The first version is read-only: it does not send, does not delete, and does not change the state of messages.

Agents have tools to read email, but they never receive the password, and message content reaches them marked as external and untrusted.

## Extensions

The IDE uses Open VSX, VSCodium's open marketplace.

## MCP servers

The **AI Resources** sidebar holds the library of agents, skills, and MCP servers. **Install MCP servers from sources** adds ready-made servers, **Set secrets** stores their keys, and **Open the IDE's mcp.json** shows the configuration. Agents receive the tools of the servers that are turned on.
