## How it works

The phone talks to the IDE through a relay, with end-to-end encryption: the relay only forwards messages that it cannot read. Remote control works while the IDE is open; there is no service running 24 hours a day.

## Pairing

1. In the IDE, run **Set up the remote access relay** once.
2. Run **Pair a device for remote access** and scan the QR code with your phone.
3. Check the device fingerprint in the IDE and confirm.

**Remote access devices** lists and revokes devices, and **Turn remote access on or off** switches everything on and off.

## On the phone

- chat with the agents;
- follow tasks and runs;
- answer decisions and permission requests;
- switch the permission mode and the Claude account;
- dictate requests;
- see the cyber café.
