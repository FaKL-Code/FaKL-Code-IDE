Sign in with **Sign in to GitHub**. The GitHub sidebar shows your whole account, not just the open repository:

- **Account:** user, organizations, and repositories, with search;
- **Assigned to me**, **Review requested**, and **My PRs**;
- **Issues** and **Actions** across all repositories, with filters;
- **Notifications** grouped by repository.

## Full screen

**Open GitHub full screen** opens a panel inside the editor with home, search, repositories, files, PRs, issues, and runs, with Markdown rendered. The token never reaches the panel.

## Actions

On a PR: review, comment, see each file's diff, check out, and merge. On an Actions run: re-run and see the job log. On an issue: **Send to agents**, which creates a task from it.

If an organization uses SSO, **Diagnose GitHub access** shows what is still missing authorization.
